# BYD ThaiVoice — Alpha 1

Fork ของ BYD DashVoice (MIT). เวอร์ชันพัฒนาท้องถิ่น ยังไม่ผ่านการทดสอบบนรถจริง

- หน้าจอและปุ่มทดสอบภาษาไทย; การรู้จำเสียง/เสียงตอบกลับยังเป็นอังกฤษ
- แยก application ID: `com.oxsacool.thaivoice`
- Freeze / Restore: เมนูทดลองเปิดหน้าจัดการแอปที่ระบบรองรับเท่านั้น ตรวจสถานะเมื่อกลับเข้าแอป ไม่บังคับหยุดแอปที่ถูกป้องกัน
- ปุ่มไมค์พวงมาลัยและเมนูทดลองปิดเป็นค่าเริ่มต้น
- ทดสอบเฉพาะแอร์ผ่านสิทธิ์ที่เฟิร์มแวร์อนุญาต ไม่ควบคุมกระจกหรือซันรูฟ

## Build

ต้องมี Android SDK, JDK และ AAR ของ Vosk/JNA ตาม build.sh ต้นฉบับ. เรียก `./build.sh` เพื่อสร้าง `build/thaivoice.apk` จากสภาพแวดล้อมที่รองรับ Bash. ไม่ต้องลงโมเดลเสียงเพื่อทดสอบปุ่มคำสั่งบนหน้าจอ.

## ทดสอบขณะจอดรถ

1. เปิดแอปและตรวจรายการสิทธิ์และ API.
2. ตรวจคำสั่งแอร์แบบแตะและตรวจผลจริงจากหน้าจอรถ หากระบบปฏิเสธให้หยุด.
3. เปิดเมนูทดลองจัดการผู้ช่วยเสียง; ใช้เฉพาะปุ่มที่ระบบให้มา และคืนค่าได้จากหน้าตั้งค่าเดียวกัน.
4. หากไม่พบแพ็กเกจผู้ช่วยเสียง ให้บันทึกผลโดยไม่ดำเนินการต่อ.

ยังไม่มีโมเดลภาษาไทยใน Alpha 1 และยังไม่ยืนยันความเข้ากันได้กับ Atto 3 รุ่นไทย.
